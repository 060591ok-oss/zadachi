1. Розв’язування рівнянь: Підбір параметра

Математичні моделі процесів описують рівняннями. В Excel рівняння з одним невідомим розв’язує засіб «Підбір параметра»: він змінює значення невідомого, доки формула не дасть потрібний результат.

Купець і сукно. 138 аршин чорного й червоного сукна коштують 540 крб (чорне — 3 крб, червоне — 5 крб за аршин). Нехай чорного x, тоді червоного 138 − x: 3x + 5(138 − x) = 540.
Як підготувати таблицю
  • Невідоме x — окрема клітинка; початково вписують будь-яке число, але не нуль (можливе ділення на 0).
  • В іншій клітинці — формула лівої частини рівняння, що посилається на клітинку з x.
  • У правій частині має бути константа — значення з умови (540).
  • ДАНІ → Аналіз «що-якщо» → Підбір параметра: вказують клітинку з формулою, її бажане значення й клітинку, що змінюється.
Кредит 1000 у. о. під 20 % на 5 років

Борг наприкінці року: Борг = Залишок + Залишок·Річні/100. Наприкінці 2-го року повертають 200, кожного наступного — по 400. Потрібно знайти внесок x першого року, щоб борг5 = 0. Це модель із ланцюжком формул, де кожен борг залежить від попереднього, а початок ланцюжка — від x. Поекспериментуйте у вкладці «Підбір параметра».

2. Оптимізаційні задачі

Оптимізаційна задача — задача, де серед багатьох варіантів потрібно знайти найкращий за певним критерієм (найбільше або найменше значення показника) з урахуванням обмежень.
🎯 Найкращий варіант → максимум чи мінімум (прибуток, час, витрати)
📈 Критерій оптимальності → те, що оптимізуємо: цільова функція
🚧 Обмеження → умови, які не можна порушувати (бюджет, ресурси, час)

Оптимізаційні параметри (змінні) — величини, від яких залежить цільова функція. Підбір параметра працює з одним невідомим, а Розв’язувач дозволяє: вказати кілька змінних клітинок, задати обмеження, обрати максимум, мінімум або конкретне значення цільової функції.

Приклад. Виробляють вироби А, B, C з доходом 13, 18, 22 у. о. за одиницю.
Цільова функція: дохід = 13a + 18b + 22c → max.
Обмеження: a + b + c = 300; a ≥ 50; b ≥ 40; c ≤ 40; a, b, c — цілі додатні.
Правила моделі в Excel і підключення Розв’язувача
  • є діапазон клітинок для оптимізаційних параметрів, клітинка з формулою цільової функції (з посиланнями на змінні);
  • увімкнення: ФАЙЛ → Параметри → Надбудови → Перейти → позначити «Розв’язувач» → ОК; команда з’явиться на стрічці ДАНІ;
  • у вікні параметрів: цільова клітинка і напрямок (max/min/значення), змінні клітинки, обмеження кнопкою «Додати», потім «Розв’язати» і «Зберегти знайдений розв’язок».
