# Рівняння та оптимізаційні задачі — інтерактивна сторінка

Один файл `index.html`, без бібліотек і без інтернету.

## Публікація на GitHub Pages
1. Створіть репозиторій і завантажте `index.html`.
2. Settings → Pages → Branch `main`, папка `/ (root)` → Save.

## Що всередині
Теорія · симуляція «Підбір параметра» (2 задачі) · перетягування (класифікація елементів моделі та порядок етапів) · симуляція «Розв’язувач» · тест · звіт із завантаженням PDF.

Спроби зберігаються в браузері учня (localStorage), тому PDF потрібно завантажувати на тому самому пристрої й у тому самому браузері.
